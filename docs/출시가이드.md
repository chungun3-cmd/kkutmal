최종 갱신: 2026-07-17

## 구조 결정 (확정)

**게임 1개 = GitHub 리포 1개 = Cloudflare Pages 프로젝트 1개 = 서브도메인 1개**

| 항목 | 값 |
|---|---|
| GitHub 리포 | `kkutmal` |
| Pages 프로젝트 | `kkutmal` → `kkutmal.pages.dev` |
| 최종 서비스 주소 | **`https://kkutmal.dobal-e.com`** |
| 게임 위치 | 리포 **루트의 `index.html`** (서브폴더 아님) |

이 패키지의 모든 링크·OG·sitemap·카카오 공유 주소는 위 기준으로 이미 맞춰져 있습니다.

## 1. GitHub에 올리기

리포 루트에 아래 파일들이 그대로 있어야 합니다 (폴더로 감싸지 마세요).

```
kkutmal/                     ← 리포 루트
├─ index.html                ← 게임 (Pages가 이걸 첫 화면으로 서비스)
├─ words.json                ← ★필수! 직접 넣어주세요
├─ words.js                  ← 로컬 테스트용 (선택)
├─ about.html / privacy.html / terms.html / contact.html
├─ articles/  (아티클 4편 + og-articles.png)
├─ og-game.png
├─ favicon.ico / favicon-32.png / favicon-16.png
├─ apple-touch-icon.png / icon-192.png / icon-512.png
├─ site.webmanifest / robots.txt / sitemap.xml / _headers
├─ README.md / .gitignore / build_words.py / docs/
```

```bash
git add .
git commit -m "feat: 끝말잇기 마스터 초기 배포"
git push origin main
```

> ⚠️ **words.json 확인 필수.** 없으면 배포는 성공하지만 게임이 "사전 파일 없음 — 표본 사전으로 실행 중"으로 뜹니다.
> (1~2MB라 GitHub 100MB 제한에는 여유. `.gitignore`는 원본 XML 덤프 폴더만 제외합니다.)

## 2. Cloudflare Pages 연결 (최초 1회, 5분)

1. Cloudflare 대시보드 → **Workers & Pages** → **Create** → **Pages** 탭 → **Connect to Git**
2. GitHub 계정 연결 → `kkutmal` 리포 선택 → **Begin setup**
3. 빌드 설정

   | 항목 | 값 |
   |---|---|
   | Project name | `kkutmal` |
   | Production branch | `main` |
   | Framework preset | **None** |
   | Build command | **비워두기** |
   | Build output directory | **`/`** |

4. **Save and Deploy** → 1분 내 `https://kkutmal.pages.dev` 배포 완료

이후 **main에 push할 때마다 자동 재배포**됩니다. 이력·롤백은 Deployments 탭.

---

## 3. 커스텀 도메인 연결

1. Pages 프로젝트 → **Custom domains** → **Set up a custom domain**
2. `kkutmal.dobal-e.com` 입력 → Continue
3. dobal-e.com이 이미 Cloudflare DNS에 있으므로 **CNAME 자동 생성** → Activate
4. 몇 분 후 HTTPS 인증서 자동 발급

## 4. 출시설정 4종 (`[출시설정]` 주석 검색)

### 4-1. 카카오 공유 (10분)
1. https://developers.kakao.com → 애플리케이션 추가하기
2. **[앱 설정 > 플랫폼 > Web]** → 사이트 도메인에 `https://kkutmal.dobal-e.com` 등록
3. **[앱 키] → JavaScript 키** 복사
4. `index.html`의 `YOUR_KAKAO_JS_KEY` 교체 → push
> 미교체 상태에서도 게임은 정상 동작 (기기 공유 → 클립보드 폴백)

### 4-2. 애드센스 (심사 1~2주)
1. https://adsense.google.com → 사이트 추가 (기존 유튜브 계정에 사이트만 추가 가능)
2. 게시자 ID로 **모든 HTML의 `ca-pub-XXXXXXXXXXXXXXXX`** 일괄 치환
3. **승인 후** 광고 단위 생성 → `data-ad-slot="0000000000"` 교체
> - 심사는 **콘텐츠 페이지 배포 완료 후** 신청 (소개·개인정보처리방침·아티클 4편이 요건)
> - 서브도메인도 dobal-e.com 도메인 승인에 포함됩니다
> - 게임 플레이 화면엔 오클릭 방지를 위해 광고 미배치 (정책 안전)

### 4-3. GA4 (선택)
`index.html`의 `G-XXXXXXXXXX` 2곳 교체 → 이벤트: `game_start`/`game_win`/`game_lose`/`share`

### 4-4. 운영 이메일
`privacy.html`, `terms.html`, `contact.html`의 `contact@dobal-e.com` 교체
